# 初芽四季主树资产

这套资产使用同一棵原创主树骨架：树冠向两侧舒展，树干较短、略厚并在底部自然加宽；左侧低位主枝横向伸展，右侧树冠略丰，重心低而稳定。四季版本只改变叶量、花朵、色彩和落叶，不改变树干比例、主要分枝与八个星光节点。

## 设计基准

- 介质：低饱和水彩、粉彩纸纹、柔化边缘。
- 树干：雾蓝、蓝灰、少量暖白干刷高光。
- 星光：八个固定暖白节点，三级尺寸，紧凑柔光。
- 构图：1254 × 1254 方形透明画布，树体外轮廓接近方形，四周保留安全空间。
- 禁止项：写实树皮、机械几何枝条、对称树冠、重复叶团、霓虹、高饱和色、水印、签名和插画背景。

## 四季状态

- `winter`：几乎无叶，蓝白雾感枝干和暖白星光。
- `spring`：稀疏嫩绿叶、少量灰粉花朵，枝条仍是视觉主体。
- `summer`：通透的灰绿色完整树冠，保留枝间空隙。
- `autumn`：米杏、浅橘、淡褐叶片和少量离枝落叶。

## 文件

- `chuya-tree-{season}.png`：1254 × 1254 高分辨率透明 PNG，适合首页和大尺寸状态展示。
- `icons/chuya-tree-{season}-icon.png`：256 × 256 透明 PNG，适合状态图标、列表和缩略展示。
- `archive-tall-v1/`：最初瘦高树资产备份。
- `archive-wide-v2-rejected/`：未采用的后续结构修正版备份；当前正式资产以第一个宽树缩略图为母版。
- `tree-assets.json`：前端路径、尺寸与季节元数据。

## 前端使用建议

```html
<img class="season-tree" src="assets/trees/chuya-tree-spring.png" alt="春季初芽树">
```

```css
.season-tree {
  width: min(82vw, 360px);
  height: auto;
  object-fit: contain;
  filter: drop-shadow(0 14px 28px rgba(0, 0, 0, 0.14));
}
```

不要额外添加强发光、饱和度滤镜或白色底板。小于 120px 宽时优先使用 `icons` 目录版本。

## 生成提示词基准

所有版本均以“同一套短厚树干、横向主枝、低重心方形构图、根部终点和八个星位”为不可变条件。冬季保留蓝白雾感裸枝；春季增加嫩叶与灰粉小花；夏季增加通透灰绿树冠；秋季增加米杏、淡橘、浅褐叶片与少量离枝落叶。生成过程禁止复制参考图构图、水印、签名和背景，并禁止写实、机械 SVG 感、镜像枝序、霓虹和高饱和色。
